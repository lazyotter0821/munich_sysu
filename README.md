# 慕尼黑 10月17-18日 行程手册

https://lazyotter0821.github.io/munich_sysu/

> 一份为慕尼黑电车 150 周年周末（2026/10/17-10/18）准备的单页行程手册，覆盖抵达、老城步行、电车巡游、Auer Dult 秋市集、Tram-Betriebshof 车辆段开放日和 Garching 酒店的全流程交通方案。

## 项目特点

- **双时区实时时钟**：顶部同时显示广州（GZ, UTC+8）和慕尼黑（MUC, UTC+2 夏令时）时间，方便对照
- **双时区时间标注**：每个行程节点同时标注 MUC 当地时间和 GZ 时间，跨日加 `+1` 标记
- **Google Maps 路线嵌入**：每段移动都嵌入 Google Maps iframe 路线图（起点 → 终点，公共交通模式），并提供「在 Google Maps 中打开完整路线」外链
- **详细乘车路线**：每段含 S-Bahn / U-Bahn / Tram / Bus / 步行的具体线路、换乘站和预计耗时
- **Mobile-first 响应式设计**：手机优先布局，桌面端自适应放大
- **离线可用**：单 HTML 文件，无外部依赖（除 Google Maps iframe 和时钟 JS）

## 出发前最后核对

1. **10月17日 Tram-Parade** 的最终开始时间、巡游路线和 Jubiläumslinie 上下车信息
2. **10月18日 Einsteinstraße 148 开放日** 的具体开放时间、入口和临时接驳 / 改线

## 交通票建议

- **10月17日**：机场 → 市区 + 市内交通，建议购买覆盖全 MVV 区间（含机场段）的日票（如 MVV Tageskarte 或 München XXL），不必买 Bayern-Ticket
- **10月18日**：主要慕尼黑市区 + Garching，全程在 MVV 范围，用 MVV App 按行程买适用区域日票 / 单程票即可
- **实时导航优先**：周年活动可能临时改线，MVV App 和 Google Maps 的实时导航比预设班次更可靠

| 时段 | 白天参考 | 早晚参考 | 旅行体感 / 建议 |

## 建议携带

按 0-15°C 准备最稳妥：长袖打底 + 针织衫 / 薄抓绒 + 防风外套；再带一件轻薄羽绒作为低温备用。裤子以长裤为主，鞋子建议适合长时间步行、具有一定防水能力的运动鞋 / 休闲鞋。

另外建议带：小折叠伞或带帽防水外套、薄围巾。如果参加正式 MBA / TUM 活动，可准备一件偏商务的外套。
